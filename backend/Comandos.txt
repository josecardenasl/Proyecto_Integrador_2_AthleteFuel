Creacion de tabla en Dynamo:

aws dynamodb create-table \
--table-name AthleteFuel \
--attribute-definitions AttributeName=id,AttributeType=S \
--key-schema AttributeName=id,KeyType=HASH \
--billing-mode PAY_PER_REQUEST \
--endpoint-url http://localhost:8000

Verificacion de que la tabla si fue creada:

aws dynamodb list-tables --endpoint-url http://localhost:8000

Inicializacion de Dynamo:

java -Djava.library.path=./DynamoDBLocal_lib -jar DynamoDBLocal.jar -inMemory -sharedDb -port 8000

Inicializacion del Backend:

npx serverless offline

Ver contenido de la tabla creada en Dynamo:

aws dynamodb scan --table-name AthleteFuel --endpoint-url http://localhost:8000

Inicializacion del Frontend:

npm run dev
